# DentResource · ทรัพยากรทันตสาธารณสุข

Dashboard ทรัพยากรทันตสาธารณสุข แสดงทันตบุคลากร ยูนิตทันตกรรม และทันตแพทย์เฉพาะทาง รายโรงพยาบาล อำเภอ จังหวัด และเขตสุขภาพ

**เปิดใช้งาน:** https://nchotenin-tech.github.io/dentresource/

## แหล่งข้อมูล
- **DentPs** (dentps.dentdata.net) — บันทึกบุคลากรรายบุคคล ในโรงพยาบาลและ รพ.สต.
- **ระบบทรัพยากรทันตกรรม กบรส.** (dental.moph.go.th) — จำนวนบุคลากรและทรัพยากรระดับเครือข่ายโรงพยาบาล
- ระดับ SAP และพิกัดโรงพยาบาล (hospital904), ข้อมูลการถ่ายโอนภารกิจ รพ.สต., กลุ่มเป้าหมายรายจังหวัด (s_pcc1)

วันที่ของข้อมูลแต่ละชุดระบุไว้ในหน้า dashboard

## ไฟล์
- `index.html` — dashboard ทั้งหมดในไฟล์เดียว (ข้อมูลและแผนที่ฝังอยู่ในไฟล์) ใช้ Chart.js, d3, topojson-client และ SheetJS จาก CDN จึงต้องต่ออินเทอร์เน็ตเมื่อเปิด

## การอัปเดต
สร้าง `index.html` ใหม่จากโปรเจกต์ต้นฉบับ (`src/build_out.py`) แล้วนำมาแทนไฟล์เดิมในรีโพนี้ GitHub Pages จะอัปเดตเองภายในไม่กี่นาที
